LUXORA — Luxury Clothing Website
=================================
VS Code-ready multi-page demo.

Pages:
- index.html — animated luxury home page
- shop.html — filters + product grid
- collections.html
- lookbook.html
- about.html
- product.html?id=1 (dynamic product detail)
- cart.html (localStorage demo cart)

Open index.html in VS Code with Live Server for the best experience.

Notes:
- Product images are loaded from Unsplash URLs, so internet is needed for those images.
- Checkout is a demo button. Connect Stripe/Razorpay/etc. for real payments.
- Replace brand name, prices, images and product details in js/app.js.
